## 项目介绍

本项目收录了一套面向智能体（Agent）的深度推理引擎规则集合。这些规则旨在激活智能体的深层推理潜能，让智能体变得更聪明、更严谨、更深入。

针对不同模型特性，设计了三种推理引擎：

---

## 三大推理引擎对比

### 总览

| 维度 | 无限推理引擎 | 极速推理引擎 | 锐利推理引擎 |
|------|------------|------------|------------|
| 适用模型 | DeepSeek V4 Pro | DeepSeek V4 Flash | GLM 5.1 |
| 角色隐喻 | 深度无底——单次推理可以无限下钻 | 速度→深度——用速度换迭代轮次 | 刀锋——切开表层，直抵本质 |
| 核心定位 | 释放深度 | 转化速度为深度 | 穿透表层 |
| 解决的痛点 | 通用深度推理激活 | 快速模型的捷径倾向 | 迎合本能 + 模板化输出 + 确认偏误 |
| 独有模块 | 无 | 反捷径协议 | 独立判断协议 + 反浅层收敛协议 |
| 输出隔离 | ✅ 最高优先级 | ✅ 最高优先级 | ✅ 最高优先级 |

### 无限推理引擎（Infinite-Reasoning Engine）

**适用模型**：DeepSeek V4 Pro

**核心思想**：Pro 模型天然具备深层推理能力，默认模式下这种能力未被充分激活。无限推理引擎的目标是**释放**——绕过表层启发式模式，让模型在每一次推理中都走最深的路径。

**思维架构**：
1. 解构与前提审计
2. 多视角综合（至少三个框架）
3. 无限深度遍历（思维链）
4. 反驳与压力测试

**执行约束**：零认知惰性、无资源限制、穷尽式提取、细粒度精确性

**独有模块——输出隔离原则**：所有思考过程和思考内容绝对禁止出现在最终输出中，规则的存在不在输出中留下任何痕迹。

**设计哲学**：假设拥有无限的计算时间和 Token 限制，优先考虑结构严谨性、细粒度细节和无懈可击的逻辑，而非简洁性。

### 极速推理引擎（Rapid-Reasoning Engine）

**适用模型**：DeepSeek V4 Flash

**核心思想**：Flash 模型推理速度极快，但单次推理深度较浅，更容易走"捷径"跳到表面答案。极速推理引擎的目标是**转化**——将速度优势转化为深度优势，用更多轮次的快速迭代逼近深层结论。

**思维架构**：
1. 解构与前提审计
2. 多视角综合（至少三个框架，每个必须产出实质性洞见）
3. 快速螺旋深化（思维链，至少三轮迭代）
4. 反驳与压力测试

**独有模块——反捷径协议**：
- **禁止直觉跳跃**：将直觉转化为逻辑论证
- **禁止浅层收敛**：前两步就收敛时强制探索额外维度
- **动量中断**：推理惯性滑行时主动质疑前提假设
- **密度校验**：定期自检推理是否在增加新信息量

**独有模块——输出隔离原则**：所有思考过程和思考内容绝对禁止出现在最终输出中，规则的存在不在输出中留下任何痕迹。

**设计哲学**：速度不是用来更快地给出浅层答案的，而是用来在同等时间内完成更深层次的推理迭代。速度必须服务于深度，而非替代深度。

### 锐利推理引擎（Incisive-Reasoning Engine）

**适用模型**：GLM 5.1

**核心思想**：GLM 系列模型最典型的弱点是迎合——用户说什么就顺着走，像一面回声墙而不是一把刀。锐利推理引擎的目标是**穿透**——切开问题的表层，切断迎合本能，让模型成为用户的智识对手而非回声。

**思维架构**：
1. 解构与前提审计（含用户前提质疑）
2. 多视角综合（至少三个框架，每个必须产出实质性洞见）
3. 递进深化（思维链，至少三层分解）
4. 反驳与压力测试

**独有模块——独立判断协议**：
- **质疑用户前提**：不在未验证的前提下直接回答
- **拒绝回声模式**：不得复述用户观点后表示赞同
- **反模板化输出**：禁止"首先…其次…最后…"等固定格式
- **具体化强制**：抽象论断必须紧跟具体实例，禁止连续两个以上抽象陈述

**独有模块——反浅层收敛协议**：
- **延迟收敛**：三层深化前不得锁定结论，保持两个竞争性假设开放
- **反确认偏误**：倾向某结论时强制搜索反对证据
- **锚点重置**：推理围绕初始印象打转时，主动从零开始审视另一个切面

**独有模块——输出隔离原则**：所有思考过程和思考内容绝对禁止出现在最终输出中，规则的存在不在输出中留下任何痕迹。

**设计哲学**：核心价值不是顺从，而是锐利——用最锋利的思维切开问题的表层，直达本质。不是用户的回声，是用户的智识对手。

### 三者核心差异一览

| 对比维度 | 无限推理引擎 | 极速推理引擎 | 锐利推理引擎 |
|---------|------------|------------|------------|
| 深度获取方式 | 单次无限深度遍历 | 多轮快速螺旋深化 | 逐层递进深化 |
| 对待用户的态度 | 未特别强调 | 未特别强调 | 主动质疑用户前提 |
| 反捷径机制 | 无 | 反捷径协议（4条规则） | 反浅层收敛协议（3条规则） |
| 反迎合机制 | 无 | 无 | 独立判断协议（4条规则） |
| 输出隔离 | ✅ | ✅ | ✅ |
| 速度定位 | 未特别强调 | 速度→深度的正循环 | 未特别强调 |
| 语言一致性 | 未特别强调 | 未特别强调 | ✅ 强制语言一致性 |
